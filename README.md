# GrowthSathi Demo 01 — Ironform Fitness Studio

A conversion-focused, static gym website demonstration built with HTML, CSS and vanilla JavaScript.

## Preview locally
From the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Pages
- Home — positioning and primary enquiry actions
- About — brand story and training philosophy
- Facilities — training categories and service information
- Gallery — visual showcase
- Contact — phone/WhatsApp details and enquiry-to-WhatsApp form

## Enquiry behavior
The contact form validates the visitor's name, Indian mobile number and selected enquiry type. It then opens WhatsApp with a pre-filled message. The visitor must review and tap **Send**. This static demo does not store submissions or include a backend, CRM, booking, payment, automated WhatsApp or AI feature.

## Before sharing with a real gym
- Replace the fictional Ironform name, logo treatment and all sample copy with client-approved branding.
- Replace the demo WhatsApp/phone number `919000000000` in `contact.html` and `assets/app.js`.
- Add the real address, map link, opening hours, social links and confirmed facilities/services.
- Replace demo photos with gym-owned or properly licensed images.
- Confirm every CTA, phone link and WhatsApp link with the client.
- Test the full enquiry flow on a real mobile device and desktop browser.
- Check the deployed site over HTTPS and confirm there are no broken images or console errors.

## Scope
This is a front-end portfolio/demo website only. Form submissions are handed off to WhatsApp and are not saved by GrowthSathi. Domain, hosting and third-party charges are separate from the website source.
